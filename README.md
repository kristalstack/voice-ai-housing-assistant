# Voice AI Housing Assistant

A Voice AI assistant that helps users understand U.S. affordable housing programs through natural spoken conversation.

The application accepts a user's voice question, transcribes the audio, generates a conversational AI response, and converts that response back into speech.

## How It Works

Voice input → Speech-to-Text → LLM → Text-to-Speech → Voice response

## Current Features

- Voice question transcription
- AI-generated housing assistance responses
- Voice-optimized conversational responses
- Text-to-speech generation
- End-to-end voice interaction through a FastAPI endpoint
- Interactive API documentation with Swagger UI
